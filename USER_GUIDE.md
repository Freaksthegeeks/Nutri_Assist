# Nutrition Assistant - User Guide

## Getting Started

Welcome to your AI-powered Nutrition Assistant! This guide will help you make the most of all the features available.

## 🚀 First Time Setup

### 1. Registration
- Click on the "Register" tab
- Enter a unique username and email
- Create a secure password
- Click "Register" to create your account

### 2. Login
- Use your username or email to login
- Enter your password
- Click "Login" to access the dashboard

### 3. Profile Setup (Important!)
- Navigate to "Profile Setup" in the sidebar
- Fill in your basic information:
  - Age, gender, height, weight
  - Activity level (sedentary to very active)
  - Diet type (balanced, vegetarian, vegan, etc.)
  - Health goals (weight loss, muscle gain, etc.)
  - Allergies and dietary restrictions
- Click "Save Profile" to store your information

## 📊 Dashboard Overview

### Home Dashboard
- View your profile completion status
- Quick access to main features
- Usage statistics and metrics

### Meal Analysis
1. Enter a meal name (optional)
2. Describe your meal in the text area:
   - "Grilled chicken breast with quinoa and steamed broccoli"
   - "Greek yogurt with berries and nuts"
   - "Pasta with tomato sauce and parmesan cheese"
3. Click "Analyze Meal" to get:
   - Nutrition score (0-100)
   - Food group breakdown
   - Personalized recommendations
   - Allergen warnings (if applicable)

### Nutrition Tracker
- View your BMI calculation
- See recommended daily calories
- Track water intake needs
- Visualize macronutrient distribution
- Get personalized nutrition tips

## 🤖 Advanced Features (Full Version)

### Weekly Meal Planning
1. Complete your profile first
2. Navigate to "Meal Planning"
3. Select week start date
4. Add special requests or preferences
5. Click "Generate Meal Plan"
6. View your personalized 7-day plan
7. Download as JSON for offline access

### Nutrition Chatbot
- Ask questions in natural language
- Examples:
  - "I want a high-protein breakfast"
  - "What are good sources of vitamin C?"
  - "Can you analyze chicken and rice?"
  - "Suggest meals for weight loss"
- Get instant responses with personalized advice

## 💡 Tips for Best Results

### Meal Descriptions
- Be specific about ingredients
- Include cooking methods (grilled, steamed, fried)
- Mention quantities when possible
- List main components clearly

### Profile Accuracy
- Keep your profile updated
- Adjust goals as they change
- Update weight and activity level regularly
- Add new allergies or restrictions

### Using the Chatbot
- Ask one question at a time
- Be specific about your needs
- Mention your dietary restrictions
- Ask for alternatives if needed

## 🔧 Troubleshooting

### Common Issues

**Login Problems:**
- Check username/email spelling
- Verify password is correct
- Try registering if account doesn't exist

**Profile Not Saving:**
- Fill in all required fields
- Check for valid numbers in height/weight
- Ensure age is between 10-120

**Meal Analysis Not Working:**
- Provide meal description
- Use common ingredient names
- Try simpler descriptions if complex meals fail

**Empty Results:**
- Check internet connection (for full version)
- Try the simplified version (app_simple.py)
- Restart the application

### Performance Tips
- Use specific ingredient names
- Keep meal descriptions clear and concise
- Update your profile regularly
- Clear browser cache if UI is slow

## 🔐 Privacy and Security

### Data Protection
- All data stored locally in SQLite database
- Passwords are securely hashed
- No personal data shared externally
- You control your information

### Account Management
- Change passwords through settings
- Export profile data as backup
- Delete account removes all data
- Session expires after inactivity
